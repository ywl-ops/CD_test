# Date Helper Skill

## 可用脚本

### get_date.py
获取当前日期和时间。

**使用方法：**
使用 `get_skill_script` 工具执行此脚本：
- skill_name: "date-helper"
- script_path: "get_date.py"
- execute: true
- args: ["%Y-%m-%d"]  # 可选：日期格式

## 何时使用
- 当用户询问当前日期或需要知道当前时间时
- 当需要格式化日期输出时
